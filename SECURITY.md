# Security Policy

## Supported versions

Security fixes are currently targeted at the latest state of the default branch.

## Reporting a vulnerability

Please do not publish exploitable details, credentials, tokens, private email samples, or personal data in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository maintainer privately through a verified channel.

Include the affected component, impact, reproduction steps, and a minimal sanitized proof of concept. Do not include working credentials or real mailbox content.

## Sensitive data

MAILTRACE may process mailbox content and authentication material. Redact personal information from bug reports and logs. Never attach real `.eml`/`.msg` files, OAuth token files, service-account keys, or production database dumps to public issues.

## Response expectations

The maintainer will assess reports, request additional sanitized details when needed, and coordinate a fix and disclosure timeline. Do not assume a report is resolved until a patched commit or release is identified.
